A memory for your browser

Pages you actually read get their text indexed on this computer, so you can find them later by any phrase you remember.

  • Everything stays here. No account, no server, no sync. Nothing is uploaded, because no code in this extension makes a network request.
  • Not everything is kept. A page has to hold your attention for a few seconds and be scrolled before it counts as read.
  • Some pages are never touched. Anything with a password field on it, and whole categories you choose in a moment.

What should it watch?

You can change this later, and switching to the second option actively gives the access back.

Never read these

Whole categories, off by default in the sense that pages matching them are not captured at all. You can add your own patterns later in settings.

How much should it keep?

Two limits, and whichever runs out first is the one that applies. Nothing is ever removed silently, and anything you pin is kept regardless.

Done

Press Ctrl Shift F to search, or type sm then space in the address bar.
