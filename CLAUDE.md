# Working conventions for this repo

This is a solo portfolio project. Commit messages should read like a normal,
professional git history — no AI attribution of any kind.

- No `Co-Authored-By` trailers, no session links, no "Generated by" footers.
- Short, descriptive commit messages: an imperative subject line, and only
  add a body when the change needs a sentence or two of "why." Never write
  multi-paragraph narrative commit messages.
- Author/committer identity should be the repo owner
  (`kernelandshell-byte <326045110+kernelandshell-byte@users.noreply.github.com>`),
  not an assistant.
